# 원산지표시 데이터 소스

## 적용 범위

HS FINDER의 국내 수입 HS CODE 조회 화면은 원산지표시 관련 정보를 두 단계로 표시한다.

- `원산지표시대상(Y)`: HS CODE가 원산지표시대상물품 별표에 포함되는지 표시한다.
- `[표시방법]`: 물품별 적정 표시방법이 구조화된 경우 표시방법을 보여주고, 구조화 전 품목은 일반원칙을 보여준다.

## 원천 자료

| 데이터 | 테이블 | 원천 | source_version |
| --- | --- | --- | --- |
| 원산지표시 대상 HS 목록 | `origin_marking_targets` | 대외무역관리규정 별표 8 원산지표시대상물품 | `origin-marking-targets-law-20260525` |
| 물품별 표시방법 | `origin_marking_methods` | 원산지제도 운영에 관한 고시 별표 3 물품별 적정 원산지표시 방법 | `origin-marking-methods-law-20260525` |

## 매칭 규칙

조회된 HSK 10자리에 대해 다음 순서로 가장 구체적인 규칙을 선택한다.

1. HSK 10자리
2. HS 6자리
3. HS 4자리
4. HS 2자리

예를 들어 `3923.50-0000`은 별표 8의 `3923` 대상 규칙과 별표 3의 `3923 플라스틱제 포장용기` 표시방법에 매칭된다.

## 운영 메모

- 별표 8은 현재 687개 HS 패턴을 구조화했다.
- 별표 3은 코드 범위와 복수 코드를 HS4 단위로 확장해 907개 표시방법 행을 구조화했다.
- 같은 HS4에 여러 물품별 표시방법이 존재할 수 있어, 화면에서는 가장 구체적인 HS 패턴의 첫 표시방법과 일반원칙을 함께 보여준다.
- 원산지표시는 품목 상태, 포장 형태, 판매 형태, 예외 규정에 따라 달라질 수 있으므로 화면에는 표시대상과 일반원칙을 함께 제공한다.
