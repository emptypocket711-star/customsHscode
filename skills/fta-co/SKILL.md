# FTA and C/O Skill

## Trigger

Use this skill when implementing or reviewing:
- FTA candidate lookup
- C/O issue method
- origin rule / PSR
- direct transport
- preferential rate comparison
- export C/O workflow

## Required Distinctions

Always distinguish:
- origin country
- export country
- shipment country
- manufacturing country
- seller country
- destination country

Do not infer FTA eligibility from shipment country alone.

## Import FTA Output

- candidate agreement
- origin country basis
- preferential rate if source exists
- C/O type
- issue method
- issuer
- validity notes
- PSR
- direct transport risk
- required evidence

## Export FTA Output

- destination agreement
- Korean-origin proof requirements
- C/O issue method
- exporter/producer responsibility
- BOM/manufacturing process/origin confirmation requirements
- buyer benefit caution

## Safety

Use “적용 가능성” and “검토 필요”.
Do not guarantee C/O acceptance or preferential tariff application.
