# Report Generation Skill

## Required Sections

1. 요약
2. 입력정보
3. HS 후보 또는 선택 HSK
4. 관세율/FTA
5. 수입요건 or 수출요건
6. 요건 취득방법
7. 고객 요청자료
8. 담당자 검토사항
9. 출처 및 조회기준일
10. 주의 문구

## Required Footer

- 조회기준일
- 생성일시
- source_version
- retrieved_at
- 담당자 승인 여부
